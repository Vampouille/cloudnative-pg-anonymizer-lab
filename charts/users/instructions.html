Goal: Configure your local tools and authenticate to the cluster.
1. Install kubectl

Make sure kubectl is installed on your machine:

# Linux (amd64)
curl -LO "https://dl.k8s.io/release/$(curl -Ls https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
chmod +x kubectl && sudo mv kubectl /usr/local/bin/

# macOS (Homebrew)
brew install kubectl

# Windows (winget)
winget install Kubernetes.kubectl
kubectl version --client
Tip: Consider also installing k9s, a terminal UI to browse pods, logs and events without typing kubectl commands. 
brew install derailed/k9s/k9s   # macOS / Linux
2. Download your kubeconfig

Click the button below (or use the toolbar button), then move the file to ~/.kube/config:

⇓ Download KUBECONFIG
3. Set your default namespace
kubectl config set-context --current --namespace=__USERNAME__
kubectl get pods

Create the following manifest and apply it:

kind: Cluster
metadata:
  name: cluster-primary
  namespace: __USERNAME__

  instances: 3
  storage:
    size: 1Gi
  # TODO: add your configuration here
kubectl apply -f cluster-primary.yaml

Wait for the cluster to be ready:

kubectl get cluster cluster-primary -w

Goal: Deploy a second cluster as a streaming replica of cluster-primary. 
apiVersion: postgresql.cnpg.io/v1
kind: Cluster
metadata:
  name: cluster-replica
  namespace: __USERNAME__
spec:
  instances: 2
  storage:
    size: 1Gi
  replica:
    enabled: true
    source: cluster-primary
  externalClusters:
    - name: cluster-primary
      connectionParameters:
        host: cluster-primary-rw.__USERNAME__.svc
        user: streaming_replica
        dbname: postgres
      # TODO: add the secret reference for replication credentials
kubectl apply -f cluster-replica.yaml
kubectl get cluster cluster-replica -w
Tip:

Goal: Promote cluster-replica to become a standalone primary. 
kubectl patch cluster cluster-replica \
  --type=merge \
  -p '{"spec":{"replica":{"enabled":false}}}'

Verify that cluster-replica now has its own primary instance:

kubectl get cluster cluster-replica
kubectl get pods -l cnpg.io/cluster=cluster-replica
